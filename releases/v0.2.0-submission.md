## What This Release Proves

This release packages the Coral hackathon submission surface into one stable version:

- three local JSONL-backed Coral tables: `candidates`, `evidence`, and `actions`
- declared Coral source tests, including a join query
- SQL ranking of public reward/prize/bounty paths
- SQL join from candidate rows to source evidence and next-action ownership
- local validation script for JSON and JSONL data
- GitHub Actions proof that the Coral CLI demo runs remotely
- GitHub Pages guide for Captain's Log / Showcase submission
